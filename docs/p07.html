To visualize the family, I use the ggpedigree function. I also tried out putting multiple pedigrees next to each other in the same plot.

For the final poster, I wanted my plot to have a transparent background, and white text, so it pops on my dark background. Then I use ggsave to download it with extra good quality so it doesn’t get fuzzy on me. In this case, I am commenting out ggsave so you can see the final thing!

Part 2: Relatedness Matrix of Family 820

First I made an interactive heat map with the default color scheme.

Next, I manually changed the default settings to get a Wake themed pallete. In the poster, the background is transparent, but that part is commented out here so its more visible here.

The Wake theme was not very visually appealing, so I returned to the default colors, and removed the ID axis labels, because they were dominating the visual.
