Portfolio 4: Using Shiny App to Make an Interactive Dashboard of Some ESM Personality Data

I was once again inspired by something we talked about in Will’s Personality Seminar. SO, for this portfolio, I will be doing an abrieviated version of the density distribution approach for mapping the relationship between trait standing and trait manifestation. The data is coming from my favorite guinea pig, my boyfriend, who was nice enough to fill out some short pseudo personality state assessment that I made. Here are my learning objectives for this portfolio piece…lets see if I succeed!

To get started with the Shiny app, I used this tutorial https://www.youtube.com/watch?v=VTI84Pqk3SI&t=1s by Grace Thompkins that was super helpful.
